# Release Note

This GitHub release package contains:

- core GeoFAR-SH source code copied from the local project;
- configuration files for paper experiments;
- renamed reproduction scripts;
- final small result summaries and LaTeX table files;
- final compact paper figures;
- CUDA change documentation and copied modified CUDA/C++ files;
- reproduction command templates;
- security and missing-file reports.

This release does not contain:

- public datasets;
- trained checkpoints;
- `.pth`, `.pt`, `.ckpt`, or `.ply` model artifacts;
- full render outputs;
- TensorBoard event files;
- temporary debugging outputs;
- local IDE metadata;
- private absolute local paths.

Before a public GitHub upload, manually confirm:

- license choice;
- author list and citation metadata;
- public repository URL;
- tested Python/PyTorch/CUDA versions;
- whether the CUDA patch should be regenerated from a clean upstream 3DGS baseline.
